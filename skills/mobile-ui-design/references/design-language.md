# 设计语言与主题

## 语义优先

颜色按用途命名：页面背景、内容表面、主动作、主动作上的文字、强调容器、主要/次要文字、装饰分隔线、交互边界、错误与成功。深浅主题共享语义和组件定义，分别提供颜色值；避免同一组件同时受主题、布局硬编码和运行时单色覆盖控制。

品牌色不等于所有状态色。错误、警告、选中、禁用的含义要清楚；不要只靠颜色表达连接状态或错误。弱分隔线可用于非必要装饰，不能充当控件唯一可辨识边界。

为真实前景/背景组合检查对比度；半透明颜色要先与实际背景合成。普通正文可按至少 4.5:1 验证；Android 大字号/粗体的具体阈值见 [官方无障碍说明](https://developer.android.com/guide/topics/ui/accessibility/apps.html)。保留系统组件的按下、焦点、选中与禁用配色，尤其不要把禁用购买按钮染成可操作主按钮。

## 可选的清爽绿色预设

[calm-green.tokens.json](../assets/calm-green.tokens.json) 提供机器可读的 light/dark 配对、间距、圆角与 Android 字号起点。来源是一次工具类 App 的实际改版；适合希望采用类似轻量风格的项目，不是移动端统一品牌规范。

其视觉意图：浅灰绿画布、白色或深色内容表面、少量绿色强调、清晰文字层级、低阴影卡片。复用时优先保持角色关系；有品牌色则替换配对并重新验证，不能只替换 primary 留下原来的 onPrimary。

## 字体、空间与密度

- 使用平台字体与语义文字样式。让标题、分区、正文和辅助信息有稳定区别；核心数值可突出，但不要挤掉状态与主要动作。
- 以 4/8 为间距节奏的起点；紧密关联用较小间距，分区之间更大。现有项目有节奏则沿用。
- 预设的 20 圆角卡片、14 圆角按钮、16–24 页面留白属于风格选择，可随品牌和内容密度调整。
- 行高和容器随文本内容增长。按钮用最小高度而非把所有语言锁在固定高度内；必要时从并排改成纵向。不要靠持续缩小字号解决溢出。
- 数值色块、图标、线条粗细与对齐基线保持一致。数据列表以扫读、比对和操作为优先，避免过度留白或每行嵌套卡片。
- 图标配动作语义；装饰图标不重复朗读旁边的文字。动效用于解释状态切换，适配减少动态效果的系统偏好。

## 自适应策略

依据可用窗口、内容长度和字体大小选择单栏/双栏，不只判断设备是否“平板”。编辑器可在足够宽时预览/表单双栏；竖屏通常让预览与设置一起滚动。固定预览只在余下区域仍足够操作时采用。

横屏高度短时先压缩重复导航与非关键说明，保留触摸目标。横竖布局保持信息顺序和状态一致，不能漏掉某个选项。大字体时允许卡片增长、操作换行，保存和取消必须仍可到达。
